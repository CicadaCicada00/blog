now lets talk about my studies im currently doing 0/1 knapsack. its already known concept. but lets see if theres anything else i can extract from this. four ways to do this:
1. Recursion.
2.memoisation(top down dp).
3.tabulation method(bottom up dp)
4.space optimised dp
recursion step is easy, summary: either you select the weight or not. as simple as that and after every recursion call finishes you simply calculate the max of notpicked weight and pickedweight. aka going through all possible combinations and storing their value. time complexity: 2^n. alright i completed the memoisation and tabulation part after both of these space optimised dp becomes self obvious.
difference between tabulation method and space optimised dp is ALOT. its like an ant infront of an elephant, the tabulation method is like a 2d array where you store all the values of the dp and space optimised dp is like a 1d array where you store only the last row of the dp.

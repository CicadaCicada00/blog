Valid bfs this is good fundamental problem, when you have adjacency list, the bfs sequence {a} is given wrt how the adjacency list is arranged, so the problem becomes to first find out how the adjacency list is arranged. how to do that? you have to follow a basic principal index[node]>=index[parent] and index[node+1]>= index[node]
maintain a index vector where you store the index of each node in the bfs sequence, after this, sort the adjacency list wrt to this index vector(make this the comparator function). 

        bool comp(ll i, ll j){
            return index[i]< index[j];
        }
        for(ll i=0;i< n;i++){
            sort(adj[i].begin(),adj[i].end(),comp);
        }

now make the bfs sequence according to the adjacency list and check if it is same as the given bfs sequence.
